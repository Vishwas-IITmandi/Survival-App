================================================================================
                          FOLDER DESCRIPTIONS
================================================================================

ROOT LEVEL FOLDERS
------------------

android/
    Purpose: Contains the Android native project files
    Contents:
      - app/           : Main Android application module
      - gradle/        : Gradle wrapper files
      - build.gradle   : Project-level Gradle build file
      - settings.gradle: Gradle settings
      - gradle.properties: Gradle configuration properties
    Used for: Building and configuring the Android version of the app

ios/
    Purpose: Contains the iOS native project files
    Contents:
      - survival/          : Main iOS application folder
      - survival.xcodeproj/: Xcode project file
      - Podfile            : CocoaPods dependencies
    Used for: Building and configuring the iOS version of the app

__tests__/
    Purpose: Contains Jest test files for unit and integration testing
    Used for: Running automated tests via `npm test`


SOURCE CODE (src/) FOLDERS
--------------------------

src/api/
    Purpose: API service layer for external communications
    Used for: Making HTTP requests, handling API responses, data fetching

src/assets/
    Purpose: Static assets used throughout the app
    Contents:
      - icons/         : Custom icon files
    Used for: Storing images, icons, fonts, and other static resources

src/components/
    Purpose: Reusable React Native components
    Contents:
      - CompassDial.tsx  : Compass dial UI component
      - DataRow.tsx      : Data display row component
      - ProgressBar.tsx  : Progress indicator component
    Used for: Building blocks that are shared across multiple screens

src/config/
    Purpose: Application configuration and constants
    Used for: API endpoints, app settings, environment variables

src/hooks/
    Purpose: Custom React hooks
    Used for: Shared stateful logic (sensors, location, etc.)

src/navigation/
    Purpose: Navigation configuration and routing
    Used for: Defining app navigation structure, tab bar, stack navigators

src/screens/
    Purpose: Main app screens/pages
    Contents:
      - ChatScreen.tsx    : AI chat interface
      - CompassScreen.tsx : Compass/navigation screen
      - ModelScreen.tsx   : LLaMA model management screen
    Used for: Top-level screen components that represent app pages

src/styles/
    Purpose: Styling and theming
    Contents:
      - globalStyles.ts       : Global/shared styles
      - chatScreenStyles.ts   : Chat screen specific styles
      - compassScreenStyles.ts: Compass screen specific styles
      - modelScreenStyles.ts  : Model screen specific styles
      - README.md             : Style documentation
    Used for: Centralized styling, theme colors, typography

src/types/
    Purpose: TypeScript type definitions
    Used for: Shared interfaces, types, and type utilities

================================================================================
                              APP FEATURES
================================================================================

1. COMPASS/NAVIGATION
   - Uses device sensors for compass functionality
   - Displays heading and orientation data
   - Components: CompassScreen, CompassDial

2. AI CHAT
   - LLaMA model integration for offline AI chat
   - Chat interface with message history
   - Components: ChatScreen

3. MODEL MANAGEMENT
   - Download and manage LLaMA models
   - Progress tracking for downloads
   - Components: ModelScreen, ProgressBar

4. LOCATION SERVICES
   - GPS location tracking via Geolocation API
   - Used for survival/navigation features
